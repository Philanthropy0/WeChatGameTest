v003 版本更新说明（2025-02-13）
======================================

【主要新增功能】
1. 角色页面标签系统重构
2. 角色属性显示优化
3. 角色面板与角色数值分离显示

--------------------------------------
js/pages/characterPage.js - 角色页面
--------------------------------------

【新增变量】
- currentTab: 'stats' | 'skills' | 'class'
  - 当前选中的标签页
  - 默认为 'stats'（属性页）

【修改导航栏】
- 从 3 个选项改为 4 个选项
- 旧：装备、道具、返回
- 新：属性、技能、职业、返回

【新增标签页功能】
1. 属性页 (currentTab = 'stats')
   - 显示角色面板：名称、等级、生命/魔法值/体力/经验值
   - 显示角色数值：攻击、防御、魔力
   - 无过渡效果，直接切换

2. 技能页 (currentTab = 'skills')
   - 显示"技能"大文本（占位符）
   - 位置居中

3. 职业页 (currentTab = 'class')
   - 显示"职业"大文本（占位符）
   - 位置居中

【角色数据模型更新】
旧数据模型：
```javascript
{
  name: '冒险者',
  level: 1,
  hp: 100, maxHp: 100,
  attack: 10,
  defense: 5,
  speed: 8
}
```

新数据模型：
```javascript
{
  name: '冒险者',
  level: 1,
  hp: 100, maxHp: 100,      // 生命
  mp: 0, maxMp: 100,        // 魔法值
  stamina: 0, maxStamina: 50, // 体力
  exp: 0, maxExp: 100,       // 经验值
  attack: 10,                // 攻击（数值）
  defense: 5,                // 防御（数值）
  magicPower: 0              // 魔力（数值）
}
```

【角色面板布局】
1. 移除头像占位符（灰白色矩形）
2. 添加"角色面板"和"角色数值"标题（后续移除）
3. 属性条显示：
   - 生命: 100/100 (红色 #e74c3c)
   - 魔法值: 0/100 (蓝色 #4a90e2)
   - 体力: 0/50 (绿色 #27ae60)
   - 经验值: 0/100 (黄色 #f39c12)

4. 每个属性条左侧显示标签（生命、魔法值等）
5. 属性条右侧显示数值（当前值/最大值）

【角色数值区域】
- 显示攻击、防御、魔力三项数值
- 无边框、无标题
- 位于角色面板下方
- 间距：角色面板 +60px → 角色数值
- 行间距：35px

【布局优化】
- 角色面板位置：centerY - boxHeight/2 - 140
- 角色面板框：280x260
- 属性条宽度：220px
- 属性条高度：20px
- 标签宽度：60px

【修改方法】
1. handleNavClick(item)
   - 添加 'stats', 'skills', 'class' 处理
   - 点击标签时直接切换 currentTab（无过渡）
   - 'back' 返回整备页面

2. render(ctx)
   - 根据 currentTab 渲染不同内容
   - 'stats' → renderCharacterInfo()
   - 'skills' → renderSkillsTab()
   - 'class' → renderClassTab()

3. renderCharacterInfo(ctx, centerX, centerY)
   - 移除头像矩形绘制
   - 添加 renderCharacterStats() 调用
   - 调整布局位置

4. renderStatBar(ctx, x, y, width, height, value, maxValue, label, color1, color2)
   - 新增 label 参数
   - 左侧显示标签名称
   - 右侧显示数值（右对齐）

5. renderCharacterStats(ctx, centerX, y) [新增]
   - 绘制攻击、防御、魔力
   - 无边框显示

6. renderSkillsTab(ctx, centerX) [新增]
   - 绘制"技能"文本占位符

7. renderClassTab(ctx, centerX) [新增]
   - 绘制"职业"文本占位符

【导航栏更新】
- itemWidth: canvas.width / 4（4个选项）
- 导航选项：属性、技能、职业、返回

js/pages/equipmentPage.js - 装备页面（新建）
--------------------------------------

【文件创建】
- 完整的装备页面类
- 包含装备槽位系统
- 底部导航栏：角色、道具、返回

【装备槽位配置】
```javascript
equipmentSlots = [
  { name: '武器', slot: 'weapon', item: null },
  { name: '头盔', slot: 'head', item: null },
  { name: '盔甲', slot: 'chest', item: null },
  { name: '护腿', slot: 'legs', item: null },
  { name: '鞋子', slot: 'feet', item: null },
  { name: '饰品', slot: 'accessory', item: null }
]
```

【功能】
- handleTouch(x, y): 处理槽位点击
- handleSlotClick(slot): 槽位点击处理（占位）
- renderEquipmentSlots(ctx): 绘制6个装备槽位
- 槽位显示：左侧名称，右侧装备信息或"空"

【导航】
- 角色 → characterPage
- 道具 → items（占位）
- 返回 → PREPARE

【注意】此文件已创建但未集成到 main.js

设计说明
--------------------------------------

【标签页设计理念】
1. 属性页：显示角色基础信息（属性条）和战斗数值
2. 技能页：预留技能树显示区域
3. 职业页：预留职业转职信息显示

【属性条颜色规范】
- 生命：红色系 - 代表生命力
- 魔法值：蓝色系 - 代表魔法能量
- 体力：绿色系 - 代表身体状态
- 经验值：黄色系 - 代表成长进度

【数值区分】
- 角色面板：资源类（可恢复、可消耗）
  - 生命、魔法值、体力、经验值
- 角色数值：能力类（固定属性）
  - 攻击、防御、魔力

【导航流程】
```
整备 → 角色 → [属性/技能/职业标签]
         ↓
      返回整备
```
