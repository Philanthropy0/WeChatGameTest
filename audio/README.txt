# 音频文件说明

本游戏需要以下音频文件，请将它们放置在 `audio/` 目录下：

## 主页音效

### fire.mp3
- **用途**: 主页背景音效（烧火的声音）
- **内容**: 淡淡的烧火声（持续循环）
- **时长**: 建议至少 10-30 秒，会循环播放
- **音量**: 建议较低音量，作为背景音效

### crack1.mp3, crack2.mp3, crack3.mp3
- **用途**: 木柴断裂音效（随机播放）
- **内容**: 木材被烧断的声音
- **时长**: 建议 0.5-2 秒
- **音量**: 中等音量
- **播放**: 在主页每隔 3-8 秒随机播放一次

## 音频格式建议

- **格式**: MP3
- **采样率**: 44.1kHz
- **比特率**: 128kbps
- **声道**: 单声道或立体声均可

## 如何获取音效

你可以从以下资源网站获取免费音效：

1. **Freesound.org** - 大量免费音效资源
2. **Zapsplat.com** - 免费音效下载
3. **Mixkit.co** - 免费音乐和音效

搜索关键词：
- "fire crackling"
- "wood crack"
- "campfire"
- "bonfire sound"

## 音频文件设置

将音频文件放入 `audio/` 目录后的结构：
```
audio/
├── fire.mp3       # 烧火背景音（必需）
├── crack1.mp3      # 木柴断裂音效1（必需）
├── crack2.mp3      # 木柴断裂音效2（必需）
├── crack3.mp3      # 木柴断裂音效3（必需）
└── README.txt       # 本说明文件
```

## 注意事项

1. 音频文件会在游戏启动时自动加载
2. 如果音频文件缺失，会在控制台显示错误但不会影响游戏运行
3. 音量可以在代码中调整（AudioManager 类）
4. 可以在设置中开启/关闭音乐和音效
